# AutomiteCreateProject

This project is made for create folder and files with one command insted of create folder then create files, this project in fact creates folder first then files one by one.

## How can you use it

In fact if you use linux, maybe you just need to clone the repository then gave executable permissions to create_project.sh then you can use it, I don't know the way to use it in other operating systems.

## Gave executable permissions to create_project.sh

```bash
chmod +x create_project.sh
```

## Run create_project.sh

```bash
./create_project.sh
```
